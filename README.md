This project presents a hybrid vision-based system for self-driving car simulation using digital image processing techniques. The system is designed to perform lane detection, obstacle detection, and driving decision-making using video-based inputs.
Autonomous driving systems require accurate interpretation of road structure and surrounding objects. In this project, a combination of classical image processing methods and deep learning-based object detection is used to build a reliable and computationally efficient solution. Classical techniques are applied for lane detection due to their effectiveness in structured road environments, while a YOLO-based model is used for detecting dynamic obstacles such as vehicles, pedestrians, and traffic signals.
The system is primarily evaluated using pre-recorded video datasets captured under different road conditions. These datasets provide controlled testing scenarios for analyzing lane detection accuracy, object recognition performance, and decision-making behavior across varying environments.
Lane detection is implemented using techniques such as color-based masking, edge detection, and Hough Transform, with an additional fallback mechanism using K-means clustering segmentation for handling cases where lane visibility is poor or inconsistent.
For obstacle detection, a deep learning model (YOLOv8) is integrated to identify relevant objects in the scene. A hybrid decision-making module combines lane geometry and detected object information to determine the appropriate driving action, such as moving forward, steering left or right, or stopping.
Although the system is primarily tested on recorded datasets, it is also structured in a modular way that allows adaptation for real-time video input with minimal changes. This ensures flexibility while maintaining a focus on controlled dataset-based evaluation for performance analysis.
